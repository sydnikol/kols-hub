## Getting Started

### Solo Play
1. Click "New Game"
2. Create character
3. Choose adventure
4. AI DM begins narration
5. Start exploring and combat
6. Progress through quests
7. Level up and improve

### Multiplayer Play
1. Player 1: "Create Session"
2. Player 2-6: "Join Session" + code
3. All create characters
4. Ready up
5. AI DM launches adventure
6. Party plays together
7. Shared progression
